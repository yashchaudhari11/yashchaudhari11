### About Me

I'm a **MERN / Next.js developer** who treats debugging as detective work, not firefighting — when something breaks, I care less about the patch and more about *why the system allowed it to break in the first place*. That mindset shapes how I build: role-based architectures, real-time systems, and workflows designed to hold up under real usage, not just demo conditions.

- 🔭 Currently building full-stack products with **Next.js** and the **MERN** stack
- 🧠 Sharpening problem-solving through consistent **DSA** practice
- ⚙️ Interested in system design, clean architecture, and real-time applications
- 📫 Reach me at the links above — always open to interesting collaborations
